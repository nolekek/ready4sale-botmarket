# 🤖 AutoShop Pro v2.4 — Готовый Telegram-бот автомагазина цифровых товаров

Профессиональный, готовый к запуску и коммерческой продаже скрипт интернет-магазина в Telegram с моментальной автовыдачей товаров, админ-панелью, реферальной системой и поддержкой популярных способов оплаты.

---

## 🚀 Основные возможности

- ⚡ **Мгновенная автовыдача 24/7:**
  - Штучные товары (аккаунты, ключи, промокоды) списываются построчно из базы.
  - Бесконечные товары (файлы, ссылки на закрытые каналы, схемы, инструкции).
- 💳 **Мульти-платежная система:**
  - **Telegram Stars (XTR)** — официальная валюта Telegram без сторонних сервисов.
  - **CryptoBot (@CryptoBot)** — прием USDT, TON, BTC, TRX, ETH.
  - **СБП / Карта РФ** — ручной перевод с подтверждением чека администратором в 1 клик.
- 👑 **Управление прямо из Telegram:**
  - Создание и удаление категорий и товаров.
  - Загрузка остатков (ключей/строк) сообщением или через `.txt` файл.
  - Подробная статистика доходов и заказов (за 24 часа и за все время).
  - Массовая рассылка сообщений и фото пользователям с обходом лимитов флуда.
  - Создание промокодов на баланс.
  - Скачивание резервной копии базы данных `shop.db` прямо в чат Telegram.
- 👥 **Маркетинг и лояльность:**
  - Партнерская (реферальная) программа с начислением процента от покупок приглашенных.
  - Личный кабинет с историей заказов и балансом.
  - Защита от спама и частых нажатий (Throttling Middleware).

---

## 🛠️ Стек технологий

- **Язык:** Python 3.10+
- **Фреймворк:** Aiogram 3.x (полная асинхронность)
- **База данных:** SQLite + SQLAlchemy 2.0 (асинхронный драйвер `aiosqlite`)
- **Конфигурация:** `pydantic-settings`, `.env`

## 🏁 Быстрый старт

### 💻 Windows
1. Переименуйте `.env.example` в `.env` и укажите ваш `BOT_TOKEN` от [@BotFather](https://t.me/BotFather) и `ADMIN_IDS`.
2. Дважды кликните по файлу **`start.bat`**.

### 🐧 Linux (Ubuntu / Debian)
```bash
cp .env.example .env
nano .env
chmod +x start.sh
./start.sh
```

### 🐳 Docker Compose
```bash
docker compose up -d --build
```
